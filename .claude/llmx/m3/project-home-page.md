## Hot tips for entering content
- Always paste in new text content using **Command + Shift + V** (aka paste without formatting). This ensures that you won't accidentally introduce formatting issues that will break material.io
- When adding content in tables, you can either manually make a table in Carbon and then copy/paste the content OR you can paste in the table, select everything (**Command + Shift + A**) and then click the "Clear Formatting" button in the text bar. Be sure to manually add a table header.

## FAQ: Carbon to Material.io
What are the steps to getting Carbon content on MIO?
- Fill this form to set up pages and tabs, and change URLs, in Kintaro: [go/m3.material.io-route-request](http://go/m3.material.io-route-request)
- Once Kintaro page and route is set up, add metadata and images to the bug created, and assign to cybage-mio@ to upload hero image and set up other

How do I preview Carbon content on MIO?
Ask Cybage for the preview link. This is automatically updated up to 30 minutes after publishing to 3P Carbon.
Content is released weekly. It's typically locked on Wednesdays and published Thursdays. For releases outside this cycle, contact cybage-mio@.
### How do I create a new page or url on M.io?
Route requests should be filed at a minimum of 2 weeks before publish date. Consider holidays, and aim to file your request 3-4 weeks out. [**Fill out a route request**](https://docs.google.com/forms/d/e/1FAIpQLSfZF49VZWvH6hVYlqa7EtX2hzQGt68KYPxIuq4eHbc9mxDVIg/viewform) when you need a:
- New page
- New tab
- Updated url or slug
- Updated page or tab name
- Moved page or tab
### How do I add an embed or code snippet on M.io?
**You don't.**
DSDB modules, Figma or other embeds in Carbon will not display on M.io.
M.io does not support Carbon’s code snippet feature. If code snippets are anticipated in an upcoming content release, please work with the M.io team to prioritize this feature.
Note: this does not apply to code snippets imported from Github/Markdown content.
